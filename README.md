# 🎮 FunkoShop

Proyecto desarrollado como trabajo práctico para la materia Programación Web.

## Tecnologías utilizadas

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap 5
- HTML
- CSS
- JavaScript

## Funcionalidades

- Registro e inicio de sesión
- Catálogo de productos
- Búsqueda de productos
- Carrito de compras con Session
- Finalización de compra
- Persistencia en base de datos mediante Entity Framework Core
